`src/orchestrator-prompt.ts` contains agy 1.5.9 native Orchestrator planning/execution semantics; `src/agent-profile.ts` appends them only for Orchestrator models. `tests/fixtures/agy-1.5.9-orchestrator-protocol.json` captures the original phase sections, and tests compare their full rule bodies with explicit adaptations for conditional phase identities, pi instruction references, and behavioral wording in place of excluded native-gate guarantees. Live isolation verified: question → no tools or handoff; action → Carbon→Hydrogen write/read; two injected write failures → `enter_plan_mode`→Carbon review→`exit_plan_mode`→Hydrogen success. Actual pi CLI E2E wrote/read `add.ts` and passed Bun assertions; the native system prompt contains the restored protocol. This is prompt-only restoration, not native hooks, gates, or scheduled review enforcement; the source is a versioned baseline, not dynamically extracted. Earlier tests also found explicit `exit_plan_mode` and `enter_plan_mode` tools necessary for handoff with `excludeDefaultComponents: true`; disabling that setting alone did not enable handoff.

In an isolated agy 1.5.9 ACP test with `gemini-pro-orchestrator`, adding frontmatter `tools: [exit_plan_mode, enter_plan_mode]` to realagy’s `excludeDefaultComponents: true` custom agent exposed native planning: it invoked `exit_plan_mode` and continued execution. Setting `excludeDefaultComponents: false` alone did not enable handoff. Both agents used the same isolated prompt and ACP model selection. Separately, the end-to-end test in `/tmp/realagy-orch-e2e` ran `pi -ne -e /root/Workspaces/realagy/extensions --model antigravity/gemini-pro-orchestrator -p ...` with a custom profile enabling both phase tools; it performed `exit_plan_mode`, then wrote and verified `add.ts` through pi-bridge. Native conversation gen_metadata identified the planner as `Orchestrator (Carbon)` and later generations as `Gemini 4 Hydrogen (Orchestrator)`; step 5 is the hidden plan handoff. This verifies an actual model switch, not merely a tool name or model self-report. Preserve Pi bridge eager tools; test trajectory sync and non-orchestrator behavior separately.

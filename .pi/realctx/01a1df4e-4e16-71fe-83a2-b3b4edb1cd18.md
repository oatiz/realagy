In agy 1.5.9, missing `ask_user_question` declarations result from pruning against `CascadePlannerConfig.customization_token_budget` (protobuf field 58; live value 20000), not `rules_token_budget` (field 59; also 20000). The Pi registry, active loadout, and outgoing MCP `tools/list` contain the full schema. Native `customizations.(*Manager).computeTruncatedCustomizations` and `customizations.CustomizationSet.IsMCPToolTruncated` implement pruning. Replaying the exact 51-tool Pi catalog through unmodified agy omitted `ask_user_question`; schema isolation, split catalogs, compacting other descriptions, and raising the effective customization budget preserved all 51 declarations, while renaming the tool to `pi_ask_user_question` did not. In complete-catalog replay, neither name appeared in request `9114ce4d-ea5f-4c6e-858e-ca67e08a6784`. Changing only the fallback constant did not work because live planner config explicitly sets 20000. Full Pi Hydrogen reproduces this; it is not Orchestrator-only, model-only exposure, or a blanket tool-count limit. Existing context-unlock and MCP-output patches do not address this declaration-pruning gate. A test patch making `IsMCPToolTruncated` return false alone did not restore the missing declaration; pruning happens earlier.

`src/acp/customization-budget-patch.ts` raises agy 1.5.9’s effective non-rules customization budget to 200000 by patching the verified full selector in `customizations.(*Manager).computeTruncatedCustomizations`. Linux/Windows x64 use matching instruction layouts; macOS arm64 uses a bounded movz/movk/branch. Realagy’s v3 derivative applies this independently of `contextUnlock`/`fullMcpOutput`; unknown layouts fail closed. All four optional patch combinations matched official Linux, Windows, and macOS binaries offline. The higher finite budget also affects non-rule customizations and can increase input cost; the rules budget is untouched.

On Linux agy 1.5.9, a copy of the current v2 context-unlock+full-MCP-output derivative was temporarily patched to set the effective non-rules customization budget to 200000, bypassing the live config override (which remained 20000). A `NODE_OPTIONS` child-process probe launched that copy only in a separate interactive Pi. The actual Orchestrator request in conversation `39435a34-6c93-4621-a948-62ca11e7a2f7` contained all 51 MCP tools, including `ask_user_question`; the model invoked it, Pi displayed the real red/blue selector, and choosing red returned to the model, which responded that red was chosen. A second question displayed again; Escape produced `no answer`, then the run was manually aborted, so end-to-end cancel continuation was not verified.

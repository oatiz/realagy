`deriveAgy` now applies `patchAgyMcpOutput` (decorator plus `src/acp/mcp-serialization-patch.ts`). It resolves `getMaxTokensForStep` and `DefaultSerializer.stepToMessage` via Go symbols, verifies unique selectors within executable code, and zeroes caps only for MCP (legacy oneof 47 / Cortex step 132). Non-MCP limits and the independent USER_INPUT context-unlock flag are preserved. `AGY_PATCH_REVISION = "v2"` in derivative filenames invalidates old source-hash-only caches. Official agy 1.5.9 Linux/Windows x64 and macOS arm64 binaries matched in both flag configurations; fixtures and instruction-execution tests cover step types 0..511. Linux live checks passed for 56,130- and 300,130-byte MCP results, a 306,697-byte `parallel` aggregate (six UUID markers), 480,130-byte USER_INPUT, and output-only mode. Windows/macOS checks are offline, not live OS tests. Installed source agy is unchanged; existing ACP processes need reload/restart to pick up v2.

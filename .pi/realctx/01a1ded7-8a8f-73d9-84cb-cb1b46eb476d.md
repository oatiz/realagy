Homebrew Cask antigravity-cli 1.5.9 changed from a direct `binary` link to `command_wrapper "agy", executable: "#{staged_path}/antigravity", env: { "AGY_CLI_DISABLE_AUTO_UPDATE" => "true" }`. `/opt/homebrew/bin/agy` symlinks to `<Caskroom>/antigravity-cli/<version>/.homebrew-command-wrappers/agy`, a generated bash env script, not a native Mach-O; the sibling `<version>/antigravity` is the actual executable. Bypassing the wrapper must preserve AGY_CLI_DISABLE_AUTO_UPDATE=true so brew remains responsible for updates. The Homebrew cask and brew Pathname#write_env_script source confirm this layout.

In agy 1.5.9 native Orchestrator tests using a custom eager pi-bridge profile, `mcp_pi-bridge_write` requested ACP permission. A direct AcpConnection probe with permissions=>'deny' ended without executing the MCP server handler; SQLite error_details recorded `permission check failed ... user denied permission`. Using permissions=>'auto' allowed the bridge write/read and native Carbon->Hydrogen execution to complete. Older observations that eager MCP tools never request permission must not be assumed for all 1.5.9 configurations. Keep probe permissions aligned with realagy driver policy.
